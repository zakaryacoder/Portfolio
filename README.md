# Portfolio (dark red editorial design)

HTML + CSS + JS, no build step.

## Customize
1. Replace `Your Name`, `your-username`, `your@email.com` in `index.html`.
2. Add your images in `assets/`:
   - Portrait: the template uses a photo by Michael Dam from Unsplash (`assets/photo.jpg`). To use your own, change the `src` of the portrait `<img>` in `index.html` to `assets/photo.jpg`.
   - `project1.svg`, `project2.svg`, `project3.svg`: generated project covers. Replace with your real screenshots (16:10) when ready.
   - `screen.jpg`: optional screenshot for the laptop mockup
3. Stock photos: download from unsplash.com or pexels.com and save them in `assets/` (do not hotlink; downloading is faster and safer). Credit the photographer if the license asks for it.

## Publish on GitHub Pages
Repo `your-username.github.io` → upload all files → Settings → Pages → Branch `main` → Save.
