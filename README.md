# Portfolio

A dark red, editorial-style developer portfolio template. Pure HTML, CSS and JavaScript, no build step, no dependencies.

## Features

- Bold hero with a large "PORTFOLIO" headline behind your portrait
- Selected projects grid with hover animation
- Education, skills and work process sections
- Contact section with a laptop mockup
- Fully responsive (desktop, tablet and phone)
- Fast: no framework, only one font request
- Accessible: keyboard focus styles and reduced-motion support

## Project structure

```
.
├── index.html       # page content
├── style.css        # all styles
├── script.js        # small helpers
└── assets/
    ├── photo.jpg    # portrait
    └── project*.svg # project covers (replace with screenshots)
```

## Getting started

1. Download or clone the repository:
   ```bash
   git clone https://github.com/zakaryacoder/Portfolio.git
   ```
2. Open `index.html` in your browser. That's it.

## Customize

1. In `index.html`, replace `Your Name` and `your@email.com` with your own details.
2. Replace `assets/photo.jpg` with your portrait.
3. Replace `assets/project1.svg`, `project2.svg`, `project3.svg` with screenshots of your projects (16:10 ratio works best), then update the file names in `index.html`.
4. Edit colors in `style.css` (variables at the top: `--red`, `--bg`, `--ink`).
